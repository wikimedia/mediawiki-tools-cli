Read the [workflow guides](/guides/) for setup and common tasks.

The manual covers command behaviour, examples and available options. Each page
identifies the release or development checkout it describes.

For project information and installation, visit [MediaWiki.org](https://www.mediawiki.org/wiki/Cli).
For help with your installed version, run `mw --help` or add `--help` to any command.

See [releases and release notes](https://gitlab.wikimedia.org/repos/releng/cli/-/releases) for downloads and what changed.

Found a problem or have an idea? [Report an issue or request a feature](https://phabricator.wikimedia.org/maniphest/task/edit/form/1/?projects=a_wikimedia_cli),
or [browse the task board](https://phabricator.wikimedia.org/project/view/5331/) to see existing work.
