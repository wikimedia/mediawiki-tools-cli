# Development environment

Develop MediaWiki and supporting services using Docker Compose. Use `--context NAME` for a separate environment, or set `CONTEXT` in your shell. `mw docker` remains an alias for existing scripts.

Start with the [setup guide](https://www.mediawiki.org/wiki/Cli/guide/Docker-Development-Environment/First-Setup). See [contexts](https://www.mediawiki.org/wiki/Cli/guide/Contexts) and [HTTP ports](https://www.mediawiki.org/wiki/Cli/guide/Ports) for environment configuration, or [service management](https://www.mediawiki.org/wiki/Cli/guide/Docker-Development-Environment/Service_Interaction) for stop, start and restart behavior.
