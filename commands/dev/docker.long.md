# Development environment

Develop MediaWiki and supporting services using Docker Compose. Use `--context NAME` for a separate environment, or set `CONTEXT` in your shell. `mw docker` remains an alias for existing scripts.

Start with `mw help guides dev setup`. Read `mw help guides dev contexts` and `mw help guides dev ports` for environment configuration, or `mw help guides dev services` for workflows across services. Use `--web` on a guide command to read it on MediaWiki.org.
